

백트래킹 - DP - Greedy 

삼지선다를 많이 걸더라

효율 순으로는 Greedy - DP - 백트래킹,
문제를 풀 수 있는 범용성으로는 백트래킹 - DP - Greedy 
인듯 싶다.

DP, Greedy 로 풀 수 있는 문제는 모두 백트래킹으로 이론적으로는 풀 수 있지만, 
성능이 안좋아서 안풀린다.

정리하면,
1) 무릎 탁 치며 (DP, 백트래킹) 안쓰고도 간단하게 풀 수 있다	-> Greedy
2) 점진적으로 배열 형태로 세이브하며 풀 것 같다				-> DP
3) 어쩔 수 없다. 백트래킹에서 가지치기 잘해서 효율 살려보자		-> 백트래킹

순서로 사고하는 게 좋을 것 같다
